# Jonathan Sells NJ — Seller-Focused Real Estate Website

A modern, high-conversion real estate platform tailored specifically for New Jersey homeowners considering selling their property. Built with Next.js, React, Tailwind CSS, TypeScript, and Framer Motion.

## Overview
- **Brand Identity:** Deep Burgundy (`#481F25`), Near Black (`#161515`), Warm Ivory (`#F6F3ED`), and Muted Stone (`#D8D3CB`).
- **Core Strategy:** Seller-first conversion hierarchy emphasizing personal representation, localized pricing intelligence, and high-impact property marketing.
- **Micro-Markets Served:** Rutherford, Montclair, Ridgewood, Maplewood, and surrounding North/Central New Jersey commuter towns.

## Key Features
- **Flagship Home Valuation (CMA):** Personalized valuation lead capture funnel with strict cybersecurity and honeypot validation.
- **Selling Process Timeline:** 4-stage transparent roadmap (Prepare, Position, Market, Negotiate & Close).
- **Marketing Showcase:** High-impact digital presentation including professional photography, GSMLS/NJMLS syndication, and targeted buyer outreach.
- **Educational Seller Resources:** Deep local guides on NJ Realty Transfer Fees, 3-day Attorney Review period, municipal CO inspections, and pricing brackets.
- **Mobile First UX:** Sticky quick-action contact bar (`Call`, `Home Value`, `Contact`), responsive layout, and app-native modal dialogs.
- **Cybersecurity & Anti-Spam:** Honeypot fields, custom client secret token headers, Cyrillic character filtering, and zero open-relay auto-responders.

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```
